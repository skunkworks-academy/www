# Ammar Boualem Zeghough - IDR Docusaurus site

This folder is a standalone Docusaurus source site configured to publish under:

`https://www.skunkworksacademy.com/idr/ammar-boualem-zeghough/`

## Manual upload target

Upload the entire folder to:

`skunkworks-academy/www/idr/ammar-boualem-zeghough/`

## Build

From this folder:

```bash
npm install
npm run build
```

Docusaurus will output the deployable static site to `build/`.

## PDF

The complete downloadable PDF is already included at:

`static/downloads/Ammar_Boualem_Zeghough_Individual_Development_Roadmap.pdf`

## Privacy

The site uses public-safe assessment information only. Private email addresses, phone numbers and sensitive personal details are intentionally omitted.

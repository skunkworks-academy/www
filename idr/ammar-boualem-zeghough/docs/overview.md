## Development objective

The roadmap converts Ammar's existing creative, managerial and practical IT strengths into a disciplined technical progression. The first objective is not to specialise too early. It is to build a reliable base in programming, web systems, Linux, networking, Git and security before choosing a deeper specialisation.

## Success definition

By the end of 12 months, Ammar should have a public-safe technical portfolio containing working software, documented labs, security evidence and at least one applied AI project. Progress is measured by deliverables, code quality, problem-solving ability and the ability to explain technical decisions.

2. **Cybersecurity:** networking, Linux, identity, defensive security, secure coding and incident fundamentals.
3. **Applied AI:** Python data tooling, model/API integration, prompt/system design, evaluation and responsible deployment.

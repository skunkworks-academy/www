# Career pathway

## Recommended pathway

**Graphic Designer -> Junior Technical Builder -> Software / Security Generalist -> Specialist**

The pathway deliberately preserves Ammar's design capability as an advantage. Front-end engineering, secure product design, developer experience, technical documentation and AI-assisted product development all benefit from strong visual communication.

### Gate 1 - Technical foundations
Demonstrate Git fluency, command-line comfort, basic Python and JavaScript, networking concepts, and a deployed static/web project.

### Gate 2 - Application builder
Build a small full-stack application with authentication, an API, tests and deployment documentation.

### Gate 3 - Security-capable developer
Perform threat modelling, secure the application, run defensive labs and document findings using responsible disclosure practices.

### Gate 4 - Applied AI builder
Integrate an AI service or local model workflow into a useful application with evaluation, guardrails and clear limitations.

### Gate 5 - Specialisation decision
Choose the strongest evidence-backed direction: software engineering, application security / SOC, or applied AI engineering.

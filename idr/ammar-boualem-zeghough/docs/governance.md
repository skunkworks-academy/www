# Governance and privacy

This IDR is designed for a public or semi-public learning environment.

## Never publish
- Personal phone numbers or private email addresses.
- Banking, payment or identity information.
- Passwords, tokens, API keys or private certificates.
- Employer/client confidential information.
- Production logs containing personal or customer data.
- Unauthorised vulnerability details or exploit instructions targeting real systems.
- Private tenant IDs, internal URLs or sensitive administrative screenshots.

## Security practice
Use local labs, synthetic data, authorised environments and intentionally vulnerable training targets. Security work must remain defensive, educational and permission-based.

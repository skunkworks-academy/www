# Study calendar

Ammar currently allocates 6-10 hours per week and indicated capacity for 11-15 additional hours. The roadmap therefore uses a **sustainable target of 17-20 hours/week**, with a maximum stretch ceiling of 25 hours.

| Day | Activity | Target |
|---|---|---:|
| Monday | Instructor-led learning / guided theory | 2h |
| Tuesday | Coding practice | 2-3h |
| Wednesday | Lab / project work | 3h |
| Thursday | Coding + security practice | 2-3h |
| Friday | Review / documentation | 1-2h |
| Saturday | Deep project block | 5-6h |
| Sunday | Rest or optional catch-up | 0-2h |

## Review cadence
- Weekly self-review.
- Fortnightly mentor or coach check-in.
- Formal review at weeks 4, 8 and 12.
- Quarterly roadmap revision after the sprint.

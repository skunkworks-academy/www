# 12-month roadmap

| Phase | Months | Focus | Required evidence |
|---|---:|---|---|
| Foundation | 1-2 | Python, JavaScript, Git, Linux, networking | GitHub exercises, CLI journal, mini web app |
| Build | 3-4 | Web apps, APIs, databases, testing | Full-stack project v1 |
| Secure | 5-6 | Security fundamentals, secure coding, defensive labs | Threat model, hardening report, security lab notes |
| Automate | 7-8 | Python automation, APIs, CI/CD, containers | Automation toolkit + pipeline |
| Apply AI | 9-10 | AI APIs/models, evaluation, RAG concepts, safety | AI-enabled application |
| Specialise | 11-12 | Chosen track + capstone | Capstone, case study, interview-ready portfolio |

## Month 1-2: foundation
Complete Python and JavaScript fundamentals, Git/GitHub workflow, Linux command line, networking basics and HTTP. Build small programs weekly.

## Month 3-4: build
Create a database-backed web application. Learn API design, authentication concepts, input validation, logging and test fundamentals.

## Month 5-6: secure
Study security principles, IAM, OWASP concepts, endpoint/network telemetry and incident basics. Harden the application created in the previous phase.

## Month 7-8: automate
Automate repetitive workflows with Python. Introduce containers and CI/CD. Add automated tests and dependency checks.

## Month 9-10: apply AI
Learn safe AI integration, prompt/system design, evaluation, retrieval concepts and privacy boundaries. Add a well-scoped AI capability to a real project.

## Month 11-12: specialise
Select a primary track based on demonstrated performance and motivation. Produce a polished capstone and prepare for role interviews or internal opportunities.

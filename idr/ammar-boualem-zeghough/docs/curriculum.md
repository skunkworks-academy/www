# Curriculum architecture

## Module A - Programming foundations
Python syntax, data structures, functions, modules, exceptions, files, testing and debugging.

## Module B - Web engineering
HTML, CSS, JavaScript, DOM, HTTP, REST APIs, Node or Python backend fundamentals, database access and deployment.

## Module C - Systems and networking
Linux, processes, permissions, TCP/IP, DNS, HTTP/TLS, common ports, basic cloud concepts and logging.

## Module D - Cybersecurity
CIA triad, identity and access, threat modelling, OWASP risks, endpoint/network telemetry, secure configuration, incident fundamentals and responsible lab practice.

## Module E - Automation and DevOps
Git workflows, CI/CD, containers, environment configuration, dependency management, automated tests and release hygiene.

## Module F - Applied AI
Python data handling, model/API integration, prompt/system instructions, structured outputs, retrieval concepts, evaluation, privacy and model limitations.

## Module G - Professional capability
Technical writing, demos, stakeholder communication, peer review, estimation, teamwork and evidence-based self-assessment.

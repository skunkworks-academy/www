# Practical labs

1. **Git lab:** branching, pull request simulation, merge conflict resolution.
2. **Python lab:** parse a CSV/JSON dataset and produce a useful summary.
3. **Web lab:** build a responsive page using semantic HTML and accessible forms.
4. **HTTP lab:** inspect requests, responses, headers, status codes and TLS basics.
5. **Linux lab:** users, permissions, services, logs and shell navigation.
6. **API lab:** consume an external API and handle failures safely.
7. **Database lab:** schema design, CRUD operations and parameterised queries.
8. **Secure coding lab:** validation, secrets, dependency review and error handling.
9. **Defensive security lab:** analyse safe sample logs and produce an incident note.
10. **CI lab:** run tests and linting automatically on each change.
11. **AI lab:** implement an AI feature and evaluate it against fixed test cases.
12. **Capstone lab:** integrate software, security and AI evidence into one project.

All labs must use authorised systems, local environments, intentionally vulnerable training targets, or synthetic data.

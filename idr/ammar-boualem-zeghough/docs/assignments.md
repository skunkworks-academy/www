# Assignments

## Assignment 1 - Technical baseline
Create a skills matrix and identify evidence already available versus capability that still needs to be demonstrated.

## Assignment 2 - Explain a system
Write a two-page technical explanation of how a browser reaches a web application, covering DNS, TCP/IP, TLS and HTTP.

## Assignment 3 - Build and review
Create a small application, request peer review and implement the feedback.

## Assignment 4 - Threat model
Produce a lightweight threat model for the application: assets, trust boundaries, threats, controls and residual risks.

## Assignment 5 - AI evaluation
Create 15-20 test cases for an AI feature and document accuracy, failure modes and mitigation.

## Assignment 6 - Career evidence review
Map portfolio evidence to target-role requirements and identify the next two highest-value gaps.

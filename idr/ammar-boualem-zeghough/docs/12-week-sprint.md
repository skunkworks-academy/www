# First 12-week applied sprint

| Week | Objective | Practical deliverable |
|---:|---|---|
| 1 | Developer environment and Git | GitHub repo, README, branching exercise |
| 2 | Python fundamentals | CLI utility with functions and error handling |
| 3 | HTML/CSS/JavaScript | Responsive portfolio page |
| 4 | Networking + HTTP | Network/HTTP notes and request inspection lab |
| 5 | Linux fundamentals | Linux command workbook and shell tasks |
| 6 | Web APIs | JavaScript or Python API client |
| 7 | Database fundamentals | CRUD app with SQLite/PostgreSQL |
| 8 | Secure coding | Input validation, secrets handling and dependency review |
| 9 | Cybersecurity lab | Defensive lab report with safe sample telemetry |
| 10 | Testing + CI | Automated test suite and CI workflow |
| 11 | AI programming | Small AI-assisted feature with evaluation cases |
| 12 | Capstone review | Demo, technical write-up and next-quarter decision |

## Weekly rhythm

- **Instructor-led session:** 2-4 hours.
- **Guided lab:** 4-6 hours.
- **Independent build:** 6-10 hours.
- **Review/documentation:** 2-3 hours.
- **Optional stretch work:** only after core evidence is complete.

## Sprint gates

**Week 4:** explain Git, HTTP, basic networking and JavaScript fundamentals.  
**Week 8:** demonstrate a working data-backed application and basic secure coding.  
**Week 12:** present a capstone with code, documentation, tests and a reflective review.

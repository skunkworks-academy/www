# Download and review

[**Download Ammar Boualem Zeghough's full IDR PDF**](/idr/ammar-boualem-zeghough/downloads/Ammar_Boualem_Zeghough_Individual_Development_Roadmap.pdf)

## Review process

1. Read the roadmap and 12-week sprint.
2. Confirm the first-quarter technical focus with the assigned mentor or manager.
3. Adjust weekly hours if the plan is not sustainable.
4. Select instructor-led courses that map directly to the curriculum.
5. Review evidence at weeks 4, 8 and 12.
6. Update the next quarter based on demonstrated capability.

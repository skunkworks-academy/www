# Development KPIs

| KPI | 12-week target | 12-month target |
|---|---:|---:|
| Public-safe GitHub repositories | 3 | 8+ |
| Completed practical labs | 10 | 35+ |
| Portfolio-grade projects | 1 | 4 |
| Automated tests on active projects | 1 project | all major projects |
| Technical write-ups | 4 | 12+ |
| Peer/mentor reviews incorporated | 3 | 10+ |
| Demonstrations/presentations | 2 | 6+ |
| Certifications | optional 1 | 2-3 evidence-aligned credentials |

## Quality gates

A deliverable counts only when it is:
1. reproducible,
2. documented,
3. safe to share,
4. reviewed or self-tested,
5. understandable to someone other than the author.

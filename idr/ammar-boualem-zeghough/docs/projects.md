# Portfolio projects

## Project 1 - Secure creative portfolio CMS
A small content-management application for design work with authentication, role separation, file handling and an audit log.

**Evidence:** architecture diagram, code, tests, security checklist and deployment guide.

## Project 2 - Security event triage dashboard
A safe local application that ingests synthetic security events and supports filtering, severity classification and analyst notes.

**Evidence:** data model, parsing code, detection logic, screenshots and incident-analysis examples.

## Project 3 - AI-assisted design brief analyser
An application that converts a design brief into structured requirements, risks, questions and an implementation checklist.

**Evidence:** prompt/system design, schema, evaluation set, limitations, privacy notes and demo.

## Capstone - Secure AI-enabled web application
Combine application development, authentication, logging, secure configuration, automated tests and a constrained AI feature.

The capstone should be deployable, documented and explainable in an interview.

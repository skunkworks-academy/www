# Credentials strategy

Certifications should support demonstrated capability rather than replace it.

## Foundation candidates
- Entry-level programming or web development credential where useful.
- Networking fundamentals.
- Linux fundamentals.
- Introductory cybersecurity credential.

## Progression candidates
Choose credentials only after practical evidence identifies the strongest pathway:

- **Software:** cloud developer / DevOps fundamentals.
- **Cybersecurity:** Security+, vendor security fundamentals or an equivalent defensive-security pathway.
- **AI:** cloud AI fundamentals followed by role-relevant applied AI certification.

## Rule

No more than one major certification objective per quarter unless the required project evidence is already on track.

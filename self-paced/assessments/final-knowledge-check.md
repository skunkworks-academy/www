# CLD-UF-101 Final Knowledge Check

**Course:** Claude User Fundamentals  
**Edition:** Online Self-Paced  
**Recommended duration:** 25–30 minutes  
**Assessment weight:** 40% of final self-paced score  
**Suggested pass mark:** 70%

---

## Learner Instructions

Answer all questions. Some questions may have more than one correct answer.

---

## Questions

### 1. Claude is best described as:

A. A traditional search engine only  
B. An AI assistant that can help with writing, summarization, brainstorming, analysis, and explanation  
C. A file backup tool  
D. A replacement for all human review

**Answer:** B

---

### 2. What is the key difference between Claude and a traditional search engine?

A. Claude never writes text  
B. Claude generates responses and does not automatically look up current webpages by default  
C. Search engines can draft emails  
D. Claude only works on mobile devices

**Answer:** B

---

### 3. What does “knowledge cutoff” mean?

A. Claude stops after ten prompts  
B. Claude may not automatically know about events or changes after a certain point unless current information is available  
C. Claude only knows one topic  
D. Claude cannot summarize documents

**Answer:** B

---

### 4. Which are common Claude workplace use cases? Select all that apply.

A. Writing and editing  
B. Summarization  
C. Brainstorming  
D. Analysis  
E. Q&A and explanation

**Answer:** A, B, C, D, E

---

### 5. Which prompt is stronger?

A. Write an email.  
B. Draft a 120-word professional reminder email to learners attending tomorrow’s online training. Include start time, laptop requirement, support contact placeholder, and a friendly tone.

**Answer:** B

---

### 6. What is the biggest weakness of a vague prompt?

A. It gives Claude too much useful context  
B. It forces Claude to guess the audience, purpose, format, and constraints  
C. It always produces no answer  
D. It automatically verifies sources

**Answer:** B

---

### 7. What should you do if Claude’s first answer is close but not good enough?

A. Accept it without review  
B. Use follow-up prompts to refine it  
C. Assume AI cannot help  
D. Use it for final sign-off

**Answer:** B

---

### 8. Which prompt element helps Claude adapt the response for the reader?

A. Audience  
B. Random spacing  
C. File name only  
D. Screen brightness

**Answer:** A

---

### 9. When should you ask Claude to ask clarifying questions first?

A. When the task is ambiguous or complex  
B. Only when writing poetry  
C. Never  
D. Only when no internet is available

**Answer:** A

---

### 10. What is a good document workflow?

A. Upload a safe and approved document, ask a targeted question, transform the result, then verify important details  
B. Upload confidential records without checking policy  
C. Ask Claude to sign a contract  
D. Ignore the source document

**Answer:** A

---

### 11. What should you check before uploading a file?

A. Whether the file is allowed, sensitive, confidential, personal, or regulated  
B. Only the file colour  
C. Whether the file name is short  
D. Nothing

**Answer:** A

---

### 12. Artifacts or reusable output panels are useful for:

A. Substantial content you want to edit or reuse  
B. Hiding all verification requirements  
C. Replacing policies  
D. Deleting project context

**Answer:** A

---

### 13. A Project is most useful when:

A. You have recurring work that benefits from shared context and files  
B. You want every conversation to be unrelated  
C. You need to store passwords  
D. You want to avoid giving Claude any context

**Answer:** A

---

### 14. Custom instructions and styles help with:

A. Repeated response preferences such as tone, format, and level of detail  
B. Replacing all prompts  
C. Making facts automatically correct  
D. Encrypting files

**Answer:** A

---

### 15. Which statement about Memory is most appropriate?

A. Memory should be used carelessly because more context is always better  
B. Memory can be useful but should be managed carefully and according to policy  
C. Memory removes the need to verify output  
D. Memory only applies to spreadsheets

**Answer:** B

---

### 16. What does “confidently wrong” mean?

A. Claude refuses to answer  
B. Claude can produce fluent output that is incorrect  
C. Claude only gives short responses  
D. Claude cannot draft emails

**Answer:** B

---

### 17. Which outputs require careful verification? Select all that apply.

A. Financial figures  
B. Legal or compliance statements  
C. Customer-facing claims  
D. Dates, names, quotes, and citations

**Answer:** A, B, C, D

---

### 18. Which task is highest risk?

A. Brainstorming internal newsletter names  
B. Rewriting a casual internal note  
C. Drafting legal wording for a client contract without review  
D. Creating a practice checklist from a sample document

**Answer:** C

---

### 19. What is the best role for Claude in high-stakes work?

A. Final authority  
B. Drafting and reasoning assistant with human verification and approval  
C. Legal signatory  
D. Replacement for policy review

**Answer:** B

---

### 20. What should a good capstone submission show?

A. A real or realistic task, a strong prompt, iteration, verification requirements, and workplace application  
B. Only a screenshot  
C. Only a single vague prompt  
D. No evidence of review

**Answer:** A

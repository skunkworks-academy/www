# CLD-UF-101 Self-Paced Grading Guide

This guide supports LMS administrators, training coordinators, and assessors reviewing self-paced CLD-UF-101 submissions.

---

## Final Score Model

| Component | Weight |
|---|---:|
| Module knowledge checks | 20% |
| Final knowledge check | 40% |
| Capstone project | 40% |
| **Total** | **100%** |

Recommended passing score: **70% overall**, with the capstone submitted and marked complete.

---

## Module Knowledge Checks — 20%

Module checks are formative but contribute to completion.

Suggested scoring:

- 8 module checks total
- Each module check is worth 2.5% of final course score
- Mark complete when learner attempts the check and reviews feedback

If the LMS does not support graded module checks, mark them as completion activities and shift weighting to:

- Final knowledge check: 50%
- Capstone project: 50%

---

## Final Knowledge Check — 40%

The final knowledge check contains 20 questions.

Scoring:

| Raw score | Percentage |
|---:|---:|
| 20/20 | 100% |
| 18/20 | 90% |
| 16/20 | 80% |
| 14/20 | 70% |
| 12/20 | 60% |
| 10/20 | 50% |

Recommended pass mark for the knowledge check: **14/20**.

---

## Capstone Project — 40%

Use the rubric below.

| Criterion | Weight | Excellent | Acceptable | Needs improvement |
|---|---:|---|---|---|
| Task selection | 10% | Realistic, relevant, clearly scoped | Relevant but basic | Unclear or unsuitable |
| Use-case fit | 10% | Correct use case or combination selected | Mostly appropriate | Poorly matched |
| Prompt quality | 20% | Context, audience, task, tone, format, and constraints included | Several key elements included | Vague or incomplete |
| Iteration | 15% | Meaningful follow-up improves output | One basic follow-up | No meaningful refinement |
| File/data handling | 10% | Safe, appropriate, and clearly described | Adequate caution shown | Sensitive/unclear handling |
| Verification plan | 20% | Specific and role-relevant checks identified | Basic checks listed | Little/no verification awareness |
| Workplace application | 15% | Clear explanation of real use and next steps | Basic explanation | Weak or missing transfer |

---

## Capstone Score Bands

| Score | Interpretation |
|---:|---|
| 90–100% | Excellent practical application |
| 80–89% | Strong application with minor gaps |
| 70–79% | Meets course standard |
| 60–69% | Needs resubmission or coaching |
| Below 60% | Does not yet meet standard |

---

## Minimum Capstone Completion Requirements

A capstone cannot be marked complete unless it includes:

- Task description
- Use case selected
- Initial prompt
- At least one follow-up prompt
- Verification list
- Workplace application explanation

## Resubmission Guidance

Learners who do not meet the standard should revise:

1. The task scope.
2. The prompt quality.
3. The follow-up refinement.
4. The verification list.
5. The workplace application explanation.

Allow one resubmission within 2 weeks unless the programme owner sets a different policy.

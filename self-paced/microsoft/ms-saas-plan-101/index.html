Learning Objectives

What delegates will be able to do

01Explain plans, SKUs, pricing models, availability, and visibility inside a Microsoft Marketplace SaaS offer.
02Create a plan with a valid immutable plan ID and marketplace-ready plan name.
03Write plan listing descriptions that distinguish feature tiers, monetization, and service limits.
04Configure markets, contract durations, billing frequency, flat-rate or per-user pricing, and optional free trials.
05Choose whether auto activation should be enabled and identify fulfillment and webhook implications.
06Differentiate public and private plan visibility and manage private audiences using Microsoft Entra tenant IDs.
07Review plan status, actions, publishing constraints, preview/test approach, and high-risk settings.
08Produce a complete SaaS plan configuration brief for a realistic offer scenario.

# Module 3 — Core Use Cases

**Estimated time:** 45 minutes  
**Course:** CLD-UF-101 — Claude User Fundamentals  
**Mode:** Online self-paced

---

## Module Purpose

This module turns Claude from an interesting tool into a practical workplace assistant. You will learn five core use cases and when to use each one:

1. Writing and editing
2. Summarization
3. Brainstorming
4. Analysis
5. Ask and explain

The goal is not to memorize features. The goal is to match Claude to the task in front of you.

---

## Learning Outcomes

By the end of this module, you will be able to:

1. Identify the five core Claude use cases.
2. Choose the right use case for a workplace task.
3. Apply Claude to one real task.
4. Use follow-up prompts to improve output.
5. Explain when output should be treated as a draft.

---

## 3.1 Use Case 1 — Writing and Editing

Claude can help with writing tasks at many stages: first draft, rewrite, tone adjustment, structure, shortening, expansion, or clarity.

Common examples:

- Emails
- Reports
- Proposals
- Meeting summaries
- Social posts
- Policies
- Standard operating procedures
- Announcements
- Briefing notes
- Sales messages

### Example Prompt

```text
Draft a professional but friendly reminder email to learners about Friday's session. Mention that they should arrive 10 minutes early, bring a laptop, and contact training support if they have access issues. Keep it under 150 words.
```

### Useful Follow-Ups

```text
Make it warmer and less formal.
```

```text
Add a subject line.
```

```text
Turn this into a WhatsApp message under 60 words.
```

### Key Lesson

Writing with Claude is iterative. The first answer is a starting point. You improve it by giving direction.

---

## 3.2 Use Case 2 — Summarization

Claude can condense long information into shorter, more useful formats.

Common examples:

- Meeting notes to action items
- Long reports to executive summaries
- Policies to plain-English explanations
- Email threads to decisions and next steps
- Articles to key points
- Transcripts to themes and follow-up tasks

### Example Prompt

```text
Summarize the following meeting notes into four sections: key decisions, open questions, risks, and action items. Keep the action items specific and assign an owner where one is mentioned.
```

### Useful Follow-Ups

```text
Now turn the action items into a checklist.
```

```text
What are the three most important risks in this summary?
```

```text
Rewrite this summary for senior leadership in one paragraph.
```

### Key Lesson

Do not just ask for “a summary.” Tell Claude what kind of summary you need and who it is for.

---

## 3.3 Use Case 3 — Brainstorming

Claude can help generate options quickly. This is useful when you are stuck, need alternatives, or want to widen your thinking.

Common examples:

- Campaign ideas
- Training activities
- Product names
- Customer engagement options
- Risk mitigations
- Process improvements
- Discussion questions
- Workshop exercises

### Example Prompt

```text
Give me 12 ideas for improving learner engagement in a half-day online AI course. Group them into low-effort, medium-effort, and high-effort ideas. Include one risk for each high-effort idea.
```

### Useful Follow-Ups

```text
Select the five ideas with the best effort-to-impact ratio.
```

```text
Make the ideas more suitable for corporate learners.
```

```text
What are the weak points in this plan?
```

### Key Lesson

Brainstorming is about quantity first, then judgement. Claude can generate options, but you choose what fits reality.

---

## 3.4 Use Case 4 — Analysis

Claude can help you compare, classify, evaluate, and structure decisions. This is especially useful when you have multiple options or messy information.

Common examples:

- Compare vendors
- Evaluate risks
- Prioritize projects
- Identify pros and cons
- Review survey themes
- Interpret simple tables
- Create decision matrices
- Build implementation plans

### Example Prompt

```text
Compare these three options using cost, implementation effort, learner impact, operational risk, and time to launch. Use a table, then recommend the strongest option with reasons.
```

### Useful Follow-Ups

```text
Add a risk rating from 1 to 5 for each option.
```

```text
Challenge your recommendation. What might make it wrong?
```

```text
Turn the recommended option into a 30-day implementation plan.
```

### Key Lesson

Claude can structure analysis, but the quality depends on the quality of your inputs. Check the logic and verify facts.

---

## 3.5 Use Case 5 — Ask and Explain

Claude can explain concepts, translate jargon, and help you prepare for unfamiliar topics.

Common examples:

- “Explain this in plain English.”
- “What should I know before this meeting?”
- “Explain this to a non-technical manager.”
- “Give me beginner, intermediate, and expert explanations.”
- “Create an analogy.”
- “Turn this technical topic into a training explanation.”

### Example Prompt

```text
Explain what an API is in plain English for a non-technical operations manager. Use a simple analogy and then give one business example.
```

### Useful Follow-Ups

```text
Make it shorter and more executive-friendly.
```

```text
Now explain the same idea to a learner with no IT background.
```

```text
Give me three questions I should ask in a meeting about this topic.
```

### Key Lesson

Claude can help you get up to speed, but current or high-stakes facts still need checking.

## 3.6 Choosing the Right Use Case

Use this quick decision table:

| Task | Best use case |
|---|---|
| Create a first draft | Writing and editing |
| Make text shorter | Writing and editing |
| Understand a long document | Summarization |
| Extract action items | Summarization |
| Generate options | Brainstorming |
| Evaluate alternatives | Analysis |
| Learn a new concept | Ask and explain |
| Prepare for a meeting | Ask and explain + analysis |
| Turn notes into a plan | Summarization + analysis |

Many real tasks use more than one use case. For example, you might summarize a meeting, analyse the risks, and then draft a follow-up email.

---

## 3.7 Worked Example — From Meeting Notes to Email

Task: You have notes from a project meeting and need to send an update.

Workflow:

1. Summarize the notes into decisions and actions.
2. Ask Claude to identify risks.
3. Ask Claude to draft an email update.
4. Refine tone and length.
5. Verify dates, owners, and commitments.

Prompt sequence:

```text
Summarize these meeting notes into decisions, action items, risks, and open questions.
```

```text
Now draft a concise email update for senior stakeholders. Use a confident but realistic tone. Include progress, one risk, and next steps.
```

```text
Make it shorter and add a clear call to action.
```

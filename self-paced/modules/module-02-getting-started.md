# Module 2 — Getting Started

**Estimated time:** 30 minutes  
**Course:** CLD-UF-101 — Claude User Fundamentals  
**Mode:** Online self-paced

---

## Module Purpose

This module gets you from theory to practice. You will open Claude, start a conversation, send a useful first message, and learn how conversation context works.

Many new users assume they need special commands. You do not. Claude is designed for natural-language conversation. If you can brief a colleague, write an email, or ask a clear question, you can prompt Claude.

---

## Learning Outcomes

By the end of this module, you will be able to:

1. Access Claude through an approved interface.
2. Start a new conversation.
3. Write a first useful prompt.
4. Use follow-up prompts to improve the answer.
5. Explain what Claude remembers inside a conversation.

## 2.1 Accessing Claude

Depending on your organization and subscription, Claude may be available through web, desktop, mobile, or an enterprise-approved environment.

Typical access routes include:

- A web browser
- A desktop app
- A mobile app
- An organization-managed workspace
- Approved integrations or internal portals

Use the access method your instructor, administrator, or organization provides.

## 2.2 Starting a Conversation

A conversation begins when you send a message. You can start with a question, a task, a draft, a document, or a problem.

A weak first message is vague:

```text
Help me with work.
```

A stronger first message is role-specific:

```text
I am an operations coordinator. What are five ways an AI assistant could help me reduce admin time each week?
```

The stronger version gives Claude context. It states the role and the goal.

---

## 2.3 Plain Language Works

You do not need code or special syntax. You can type naturally.

Useful prompt starters:

- Help me draft...
- Summarize this...
- Explain this in plain English...
- Compare these options...
- Turn this into a checklist...
- Ask me questions before you answer...
- Make this more concise...
- Rewrite this for an executive audience...

The clearer your request, the better the result.

---

## 2.4 Conversation Context

Claude remembers what has already been said inside the current conversation. This means you can use follow-up prompts without restating everything.

Example conversation flow:

1. You ask Claude to draft an email.
2. Claude writes a first draft.
3. You say, “Make it warmer and shorter.”
4. Claude understands that “it” means the email from the previous response.
5. You say, “Add a clear call to action.”
6. Claude continues refining the same draft.

This is why Claude is most useful as a conversation, not a one-shot command.

---

## 2.5 New Conversations Start Fresh

A new conversation does not automatically include everything from previous conversations unless you are using features such as Projects, Memory, or connected context enabled in your environment.

Use this rule:

> If Claude needs background to do the task well, provide the background in the conversation or use an approved context feature.

For example, do not assume Claude knows:

- Your company structure
- Your customer requirements
- Previous meeting decisions
- Your preferred writing style
- Internal acronyms
- Current project status

You must provide that information unless it is already available in the current conversation or approved workspace context.

---

## 2.6 A Practical First Workflow

Use this simple workflow for your first useful Claude interaction:

1. State your role or situation.
2. State the task.
3. State what good output looks like.
4. Ask for the first draft.
5. Refine with follow-up prompts.

Example:

```text
I manage weekly training coordination for a small team. Help me draft a short update email for learners. The email should confirm the session date, remind them to bring a laptop, and sound professional but friendly. Keep it under 150 words.
```

Follow-up:

```text
Make it more concise and add a subject line.
```

Second follow-up:

```text
Now turn it into a WhatsApp message under 60 words.
```

---

## 2.7 When to Start a New Conversation

Start a new conversation when:

- You are switching to a different topic.
- The current conversation is cluttered.
- You want to avoid mixing client or project contexts.
- You are working on a new document or task.
- You want a clean starting point.

Continue the same conversation when:

- You are refining the same output.
- Claude needs the existing conversation context.
- You are building on earlier decisions.

## Try It Yourself

Complete this activity in Claude:

1. Start a new conversation.
2. Send a role-based prompt:

```text
I work as a [your role]. What are five practical ways Claude could help me in a normal work week?
```

3. Choose one suggestion from Claude’s answer.
4. Ask a follow-up:

```text
Show me exactly how I could use Claude for option [number]. Give me a simple workflow and one example prompt.
```

5. Save the example prompt in your learner workbook.

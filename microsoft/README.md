# Microsoft Training Catalogue

This folder contains the Microsoft Training Catalogue content that is served through the Skunkworks Academy unified site.

## Canonical URL

- https://skunkworksacademy.com/microsoft/
- Source path: `skunkworks-academy/.github/microsoft/`

## Migration note

The public GitHub Pages route previously used for Microsoft content was:

- https://skunkworks-academy.github.io/microsoft/

Microsoft catalogue content now lives under this `.github/microsoft` folder so it can share the Academy global navigation, styling, SEO metadata, learner routing, and ecosystem links.

## Primary files

- `index.html` — Microsoft catalogue landing page.
- `*.html` — Microsoft category pages for Azure, Microsoft 365, Office, Power BI, Power Platform, Security, Teams, SharePoint, SQL Server, Windows, Dynamics and related training areas.

## Operational guidance

When updating Microsoft training content:

1. Keep `index.html` as the main discovery page.
2. Preserve relative links between Microsoft category pages.
3. Use the canonical Academy URL for public references.
4. Confirm all new pages include useful metadata, accessible headings, and learner-facing calls to action.
5. Route enquiries to `training@skunkworksacademy.com` or the Academy contact workflow.

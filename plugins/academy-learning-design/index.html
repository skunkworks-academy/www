Designed for reviewability

Quality is verified, not assumed

Build an auditable evidence trail for learning design and the finished website.

Academy release standards

  • Accessible by design. Aim for WCAG 2.2 AA, readable contrast, semantic structure and keyboard operation; verify the actual page in both themes.
  • Instructionally aligned. Link every assessment and practical activity to an observable learning outcome.
  • Secure learning operations. Keep restricted learner data, proprietary content and graded assessment records out of public GitHub Pages artifacts.
  • Consistent publication. Verify global navigation and footer, enrolment paths, site assets, responsive layout, metadata and sitemap registration.

Before you begin

Questions about using the plugin

Can anyone install or use the plugin?

Not currently. This is a private plugin in its owner's ChatGPT account. The plugin link may require signing in and an authorised connection; a public web landing page does not grant plugin access.

Does the plugin build and publish courses automatically?

No. It supplies instructional-design skills, blueprints, review criteria and release guidance. Publishing, GitHub edits and LMS operations depend on separately connected tools, permissions and passing checks.

Does it certify an ISO-compliant course?

No. It helps identify relevant quality requirements, map learning evidence and document gaps. Formal conformity claims require an appropriate independent, documented assessment.

Where should learner assessments and confidential files be stored?

In an authenticated LMS or approved protected document service with access control, audit logs and retention policies. Do not embed sensitive records or private answer keys in public static pages.

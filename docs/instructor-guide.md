# CLD-UF-101 — Claude User Fundamentals
## Instructor Facilitation Guide

**Audience:** Knowledge workers and business users with no technical background required  
**Duration:** Half-day, approximately 3–4 hours including breaks  
**Format:** Instructor-led with hands-on practice throughout

---

## How to Use This Guide

Each unit includes:

- Time allocation
- Core talking points
- Discussion prompts
- Hands-on activity instructions
- Instructor notes and facilitation reminders

The course is designed to be practical, conversational, and confidence-building. Avoid turning the session into a technical lecture. Learners should spend meaningful time using Claude on real or realistic work.

## 1. Introduction to Claude — 20 minutes

### Instructor Goal

Ground learners in what Claude is before they touch the keyboard.

### Talking Points

- Claude is an AI assistant built by Anthropic.
- It helps with writing, analysis, coding, summarization, brainstorming, and conversation.
- Claude is not a search engine by default.
- Claude has a knowledge cutoff and may need web search for current information.
- Claude can make mistakes or hallucinate.
- Claude should be used to augment judgement, not replace it.

### Discussion Prompt

> Has anyone here used an AI assistant before? What worked, and what did not?

### Instructor Notes

- Set expectations early.
- Acknowledge job-replacement concerns honestly.
- Position Claude as a productivity multiplier and thinking partner.
- Do not overpromise accuracy.

---

## 2. Getting Started — 25 minutes

### Instructor Goal

Get everyone logged in and comfortable sending a first message.

### Talking Points

- Claude is available via web, desktop, and mobile.
- Conversations sync across devices using the same account.
- Learners can type naturally; no command syntax is required.
- Claude remembers context within a conversation.
- New conversations start fresh unless Memory is enabled.
- Model tiers exist, but most users can start with the default.

### Hands-On Activity

Ask learners to:

1. Open Claude.
2. Start a new conversation.
3. Ask: “What are some ways an AI assistant could help someone in my role as a ___?”

### Instructor Notes

- Walk the room during login and first-prompt activity.
- Look for participants who are hesitant and support them early.
- Preview that Memory is handled later in the course.

## 3. Core Use Cases — 40 minutes

### Instructor Goal

Show five practical ways Claude can be used at work.

### Use Cases to Demonstrate

#### 1. Writing and Editing

Examples:

- Draft an email.
- Rewrite a message in a different tone.
- Shorten or expand a report section.

#### 2. Summarization

Examples:

- Summarize a long email thread.
- Extract action items from meeting notes.
- Condense a document into key decisions.

#### 3. Brainstorming

Examples:

- Generate options.
- Use a framework such as pros/cons or SWOT.
- Pressure-test a plan.

#### 4. Analysis

Examples:

- Compare options against criteria.
- Interpret a table of data.
- Identify risks and trade-offs.

#### 5. Q&A / Research Support

Examples:

- Explain a concept in plain language.
- Translate jargon.
- Prepare for a meeting.

### Discussion Prompt

> Looking at your own role, which of these five use cases would you reach for most often?

### Hands-On Activity

Learners choose one use case and complete a real or realistic task.

### Instructor Notes

- Encourage real work rather than toy examples.
- Watch for vague prompts; these become inputs for Unit 4.
- Reinforce iteration: the first output is usually a draft, not the final product.

## 4. Effective Prompting — 35 minutes

### Instructor Goal

Teach the single highest-leverage skill: asking for what you actually want.

### Talking Points

- Be clear and specific.
- Provide context Claude cannot see.
- Give examples of the desired output.
- Iterate with follow-up instructions.
- Ask Claude to ask clarifying questions before producing output.

### Before / After Demo

Weak prompt:

> Write a project update.

Strong prompt:

> Write a 150-word project status update for senior leadership. Tone: confident but realistic. Include current progress, one risk, and the next milestone.

### Discussion Prompt

> What is one prompt you tried earlier that did not give you what you wanted? Let’s improve it together.

### Hands-On Activity

Learners revise one prompt from Unit 3 using audience, context, length, tone, constraints, and format.

### Instructor Notes

- This unit often creates the biggest “aha” moment.
- Do not frame prompting as magic syntax.
- Frame it as briefing a capable colleague properly.

---

## 5. Working with Documents and Files — 30 minutes

### Instructor Goal

Move learners from generic prompting to working with their own materials.

### Talking Points

- Claude can read uploaded files such as PDFs, Word docs, spreadsheets, images, slide decks, and text files.
- Common tasks include summarizing, extracting data, finding inconsistencies, and rewriting sections.
- Artifacts are useful for substantial outputs such as tables, drafts, code, or structured plans.

### Hands-On Activity

Learners upload a real document and ask Claude to:

1. Summarize it.
2. Answer one specific question about its contents.

### Instructor Notes

- Remind learners not to upload confidential material unless their organization permits it.
- If the client has approved connectors such as Drive or Slack, mention that integrations are possible but not the focus of this session.

---

## 6. Projects and Memory — 25 minutes

### Instructor Goal

Show how Claude can support recurring tasks by carrying context forward.

### Talking Points

- Projects group related conversations and reference files.
- Custom instructions and styles define how Claude responds by default.
- Memory is optional and user-controlled.
- Memory should be handled carefully in organizational contexts.

### Discussion Prompt

> What recurring task in your role would benefit from saved context?

### Instructor Notes

- Keep this practical and use examples: weekly reports, client accounts, product lines, recurring proposals.
- Do not oversell Memory; some organizations may disable or restrict it.

---

## 7. Best Practices and Pitfalls — 25 minutes

### Instructor Goal

Give learners a practical risk model for using Claude responsibly.

### Talking Points

- Claude can be confidently wrong.
- Fluency is not the same as accuracy.
- The higher the stakes, the more verification is required.
- Treat names, numbers, dates, citations, legal wording, financial figures, and customer-facing claims as verification items.
- Do not paste sensitive or confidential data unless approved by organizational policy.

### Discussion Prompt

> Where in your own work would AI output need extra caution?

### Instructor Notes

- Frame this as empowerment, not fear.
- The best users know where to double-check.
- Defer policy-specific questions to the organization’s AI/security/data-governance owner.

---

## 8. Hands-On Practice and Q&A — 30 minutes

### Instructor Goal

Ensure every learner leaves having completed one useful task.

### Activity

Learners complete one real task end to end:

1. Pick a real task.
2. Choose the right use case.
3. Write a sharp prompt.
4. Use a document if helpful.
5. Iterate on the result.
6. Verify what matters.

### Q&A Prompt

> What is one thing you are still unsure about?

### Closing Prompt

> Name one thing you will try with Claude this week.

### Instructor Notes

- This is mostly work time, not lecture time.
- Coach individually.
- Confirm lab completion for assessment records.

---

## Instructor Delivery Checklist

Before class:

- Confirm learners have Claude access.
- Confirm room, projector, internet, and microphone setup.
- Prepare one safe demo document.
- Prepare a short quiz link or printed quiz.
- Review the client’s AI/data policy if available.

During class:

- Use live demos.
- Walk the room during every activity.
- Keep examples workplace-relevant.
- Encourage iteration.
- Reinforce verification.

After class:

- Record quiz scores.
- Record lab completion.
- Issue certificates where criteria are met.
- Send follow-up resources and office-hours details.

# CLD-UF-101 Facilitation Plan

This plan supports a half-day instructor-led delivery of **Claude User Fundamentals**.

---

## Delivery Principles

1. **Practical first:** demonstrate, then let learners try.
2. **No jargon unless useful:** explain AI concepts in workplace language.
3. **Real work beats sample work:** encourage tasks learners actually need to complete.
4. **Iteration is the method:** the first output is a draft.
5. **Verification is mandatory for high-stakes work:** names, numbers, dates, quotes, citations, legal/compliance content, financials, and customer-facing material must be checked.

---

## Recommended Setup

### Instructor Equipment

- Laptop with Claude access
- Projector or screen share
- Stable internet
- Safe demo files for upload practice
- Quiz delivery method: LMS, form, or printed sheet
- Attendance and lab review tracker

### Learner Requirements

- Laptop or tablet
- Internet access
- Claude account
- One safe work-related task or document

## Demo Prompt Bank

### Unit 1: What Claude Is

```text
Explain Claude to a non-technical business user in 100 words. Include one limitation.
```

### Unit 2: First Message

```text
What are some ways an AI assistant could help someone in my role as a project coordinator?
```

### Unit 3: Core Use Cases

```text
Draft a friendly reminder email about Friday's deadline. Keep it under 120 words.
```

```text
Summarize this meeting note into decisions, risks, and action items.
```

```text
Give me 10 ideas for improving learner engagement in a half-day AI course.
```

```text
Compare these three options on cost, implementation effort, learner impact, and risk.
```

```text
Explain what an API is in plain English for a non-technical manager.
```

### Unit 4: Prompt Improvement

Weak:

```text
Write a project update.
```

Improved:

```text
Write a 150-word project status update for senior leadership. Tone: confident but realistic. Include current progress, one risk, one blocker, and the next milestone. Format it as concise bullet points.
```

### Unit 5: Document/File Prompt

```text
Summarize this document in five bullets, then list three questions I should ask before using it with a client.
```

### Unit 7: Verification Prompt

```text
Review this output and identify which statements require verification before I send it to a client.
```

## Common Questions and Suggested Responses

### Does Claude replace search engines?

No. Claude can explain, draft, reason, and work with context, but it does not automatically look things up by default. For recent or high-stakes facts, use web search or trusted source verification.

### Can I upload company documents?

Only if your organization permits it. Follow approved AI, data security, privacy, and confidentiality policies.

### Does Claude remember everything?

Claude remembers context within the current conversation. Across separate chats, context is not automatically carried unless Memory or Projects are used and enabled.

### Which model should I use?

For this course, learners can start with the default model. Model selection becomes more important in technical or high-volume use cases.

## Lab Review Notes

For the final lab, the instructor should confirm that the learner:

- Used a real or realistic task.
- Wrote a prompt with context and clear intent.
- Iterated at least once.
- Used a document or file if appropriate.
- Identified what needed verification.
- Could explain how they would apply the output.

Use the rubric in `assessments/lab-review-rubric.md`.

# CLD-UF-101 Hands-On Lab Review Rubric

**Assessment Weight:** 60%  
**Aligned Unit:** Unit 8 — Hands-On Practice and Q&A  
**Purpose:** Confirm that the learner can apply course concepts to a real or realistic work task.

---

## Scoring Summary

| Criterion | Weight |
|---|---:|
| Task selection and use-case fit | 15% |
| Prompt quality | 25% |
| Iteration and refinement | 15% |
| Document/file usage where appropriate | 10% |
| Verification and responsible use | 20% |
| Explanation and transfer to real work | 15% |
| **Total** | **100%** |

---

## Rubric Detail

### 1. Task Selection and Use-Case Fit — 15%

| Score | Description |
|---:|---|
| 0 | No clear task selected. |
| 1 | Task selected but not relevant to learner’s work. |
| 2 | Task is realistic but use case is unclear. |
| 3 | Task is relevant and mapped to a suitable use case. |
| 4 | Task is highly relevant and clearly aligned to one or more course use cases. |

---

### 2. Prompt Quality — 25%

| Score | Description |
|---:|---|
| 0 | Prompt is missing or unusable. |
| 1 | Prompt is vague and lacks context. |
| 2 | Prompt includes basic intent but limited detail. |
| 3 | Prompt includes audience, context, tone, length, or output format. |
| 4 | Prompt is specific, contextual, constrained, and likely to produce reusable output. |

Prompt quality indicators:

- Audience is clear.
- Purpose is stated.
- Context is provided.
- Output format is specified.
- Tone and length are included where relevant.
- Constraints or must-have details are stated.

---

### 3. Iteration and Refinement — 15%

| Score | Description |
|---:|---|
| 0 | No iteration attempted. |
| 1 | Minimal follow-up with no meaningful improvement. |
| 2 | At least one useful refinement attempted. |
| 3 | Learner refined tone, format, structure, or completeness. |
| 4 | Learner used multiple targeted refinements and can explain the improvement. |

---

### 4. Document/File Usage Where Appropriate — 10%

| Score | Description |
|---:|---|
| 0 | File use was required but not attempted. |
| 1 | File uploaded or referenced but not used effectively. |
| 2 | File was used for summarization or basic Q&A. |
| 3 | File was used to extract, transform, compare, or structure information. |
| 4 | File use produced a practical reusable output such as a table, checklist, summary, or draft. |

If no file is relevant to the learner’s task, award based on whether the learner can explain why file use was not required.

---

### 5. Verification and Responsible Use — 20%

| Score | Description |
|---:|---|
| 0 | Learner cannot identify any verification needs. |
| 1 | Learner identifies generic risks only. |
| 2 | Learner identifies at least one specific item requiring verification. |
| 3 | Learner identifies multiple verification points such as figures, names, dates, claims, or policy-sensitive content. |
| 4 | Learner clearly explains a practical verification plan and demonstrates responsible data handling. |

Verification indicators:

- Facts, figures, dates, names, quotes, citations, legal/compliance content, and customer-facing statements are checked.
- Sensitive or confidential information is handled according to policy.
- Claude is treated as a drafting and reasoning assistant, not final authority.

---

### 6. Explanation and Transfer to Real Work — 15%

| Score | Description |
|---:|---|
| 0 | Learner cannot explain how they would use the result. |
| 1 | Explanation is unclear. |
| 2 | Learner can describe basic use of the result. |
| 3 | Learner explains how the output supports a real task and what happens next. |
| 4 | Learner explains how they will adapt the workflow to future tasks. |

---

## Final Lab Score Calculation

Use this formula:

```text
Lab Score = Weighted score across all six criteria
Final Course Score = (Quiz Score × 0.40) + (Lab Score × 0.60)
```

Learners pass the course when:

- Combined score is 70% or higher.
- Final lab activity is completed and reviewed.

---

## Instructor Review Checklist

Before marking the lab complete, confirm that the learner can show or explain:

- The task they selected
- The use case they applied
- Their initial and improved prompt
- At least one follow-up refinement
- Any document/file used, where applicable
- What must be verified before using the output
- How they will apply the result in real work

# CLD-UF-101 Knowledge Quiz

**Assessment Weight:** 40%  
**Recommended Duration:** 15 minutes  
**Passing Contribution:** Combined course score must be 70% or higher.

---

## Instructions for Learners

Choose the best answer for each question. Some questions may ask for more than one answer.

---

## Questions

### 1. What is Claude best described as?

A. A spreadsheet application  
B. An AI assistant that can help with writing, analysis, coding, and conversation  
C. A database server  
D. A password manager

**Answer:** B

---

### 2. Why should Claude not be treated exactly like a search engine?

A. It cannot type text  
B. It only works offline  
C. It generates responses and does not automatically look things up by default  
D. It can only answer mathematical questions

**Answer:** C

---

### 3. What does “knowledge cutoff” mean?

A. Claude stops responding after a fixed number of prompts  
B. Claude may not automatically know about events after a certain point in time unless current information is retrieved  
C. Claude only knows information from one website  
D. Claude only works with uploaded files

**Answer:** B

---

### 4. Which of the following are core use cases covered in this course? Select all that apply.

A. Writing and editing  
B. Summarization  
C. Brainstorming  
D. Physical network cabling

**Answer:** A, B, C

---

### 5. What is usually the biggest reason a Claude response is too generic?

A. The prompt did not provide enough context  
B. The learner used a laptop instead of a phone  
C. Claude cannot write in paragraphs  
D. The prompt was too polite

**Answer:** A

---

### 6. Which prompt is stronger?

A. “Write something about policy.”  
B. “Write a 150-word email to staff announcing the new remote-work policy. Use a warm tone and include the start date, what changes, and who to contact with questions.”

**Answer:** B

---

### 7. What should you do when Claude’s first response is close but not quite right?

A. Start over immediately  
B. Delete the account  
C. Iterate with a follow-up instruction  
D. Assume Claude cannot help

**Answer:** C

---

### 8. Which files can Claude commonly help work with in this course context?

A. PDFs  
B. Word documents  
C. Spreadsheets  
D. Images and screenshots

**Answer:** A, B, C, D

---

### 9. What are Artifacts useful for?

A. Substantial reusable outputs such as documents, tables, drafts, code, or structured plans  
B. Replacing all file storage systems  
C. Encrypting passwords  
D. Blocking email spam

**Answer:** A

---

### 10. What is a Project useful for?

A. Grouping related conversations and shared context for repeated work  
B. Resetting Claude after every answer  
C. Turning Claude into a spreadsheet only  
D. Preventing prompts from being edited

**Answer:** A

---

### 11. Which statement about Memory is most accurate?

A. Memory is always mandatory  
B. Memory is optional and should be managed carefully  
C. Memory only works for images  
D. Memory replaces verification

**Answer:** B

---

### 12. What does “confidently wrong” mean?

A. Claude refuses to answer  
B. Claude can state an incorrect fact fluently and confidently  
C. Claude only gives short answers  
D. Claude always cites official sources

**Answer:** B

---

### 13. Which outputs should be verified before use? Select all that apply.

A. Legal or compliance wording  
B. Financial figures  
C. Customer-facing claims  
D. Names, dates, citations, and quotes

**Answer:** A, B, C, D

---

### 14. What should you do before uploading sensitive company or customer data?

A. Upload it without checking  
B. Follow your organization’s approved AI, privacy, and data handling policy  
C. Rename the file only  
D. Paste it into every conversation for context

**Answer:** B

---

### 15. What is the best final role for Claude in high-stakes work?

A. Final decision-maker  
B. Fast drafting and reasoning assistant, with the human responsible for review and sign-off  
C. Legal authority  
D. Replacement for all expert review

**Answer:** B

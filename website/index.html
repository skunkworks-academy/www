CLD-UF-101

Claude User Fundamentals

A half-day, instructor-led course that helps business users apply Claude to real work: writing, summarization, brainstorming, analysis, prompting, document workflows, Projects, Memory, and responsible use.

View Course Repository

At a Glance

Duration

Approximately 3 hours 50 minutes including breaks

Audience

Knowledge workers and business users

Prerequisites

None beyond basic computer and internet literacy

Assessment

Quiz 40% + hands-on lab review 60%

What Learners Will Do

Start a Claude conversation and ask role-relevant questions.
Draft, summarize, brainstorm, analyse, and explain using real workplace examples.
Improve prompts using context, audience, tone, constraints, and format.
Upload safe documents and ask useful questions about them.
Use Projects and Memory concepts for recurring work.
Build a verification checklist for high-stakes output.

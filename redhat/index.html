Certification preparation

Role-based learning paths

Each path combines prerequisite assessment, instructor guidance, hands-on lab work, revision checkpoints and an exam-readiness review.

Red Hat Certified System Administrator (RHCSA)

Foundation pathway for administrators responsible for core Red Hat Enterprise Linux operations.

  • Recommended sequence: RH124 and RH134, or RH199 for experienced Linux administrators
  • Practical preparation aligned to the EX200 performance-based exam
  • Core administration, storage, services, networking, security and basic containers

Red Hat Certified Engineer (RHCE)

Advanced pathway focused on automating Linux administration and scaling consistent operations.

  • Builds on current RHCSA-level capability
  • Automation skills commonly developed through RH294
  • Playbooks, roles, configuration management and operational automation

OpenShift Administrator

Platform operations pathway for teams managing containerised applications on Red Hat OpenShift.

  • Cluster administration and application operations
  • Security contexts, networking, persistent storage and access control
  • Troubleshooting and preparation for applicable OpenShift administration exams

OpenShift Developer and DevOps

Application delivery pathway for developers and engineers building and operating cloud-native workloads.

  • Containers, Kubernetes resources and OpenShift developer workflows
  • Builds, deployments, configuration, routes and CI/CD
  • Advanced options for microservices, service mesh and application modernisation
